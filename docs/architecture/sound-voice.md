## A8 Sound and voice

| Part | Detail | Status |
|---|---|---|
| Data sweep | Spectrum to pitch with a triangle oscillator. Bell chimes at gas wavelengths. Stereo sweep. Web Audio in the browser. The same events drive the spectrum haptics, so sound and touch match (rendering doc §8.6). | Built in the Listen tab. Syntax checked, never heard by the author. |
| Imagined drive | Procedural noise, gravel and thuds shaped by gravity, roughness and surface type from the card. Always labelled "Imagined". | Built, unheard |
| Audio pairing | Every haptic event also plays as sound, on every platform, with its own on/off switch and volume. Audio carries continuous strength (gain), pitch, stereo pan and provenance by timbre: clean tone for `measured`, grainy click for `artistic` (D-10, rendering doc §8.9). | To build |
| AI sound clips | Post-event backlog (B-03). | Not built for the event |
| Voice control | Gemini Live. Post-event backlog (B-02). | Not built for the event |

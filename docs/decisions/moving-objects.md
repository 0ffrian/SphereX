# Decisions: Moving objects: Track and Area search

> **Part of:** the decision log ([index](README.md)) · **Holds:** Rainbow Trails, the Track tool, Area search and Discovery · **Authority:** highest; an entry here wins over [rendering/](../rendering/README.md) and [architecture/](../architecture/README.md) (see the index for precedence)

## D-28 Rainbow Trails is a flipbook view mode (answers Q-04)

- **Decision:** Rainbow Trails (handover §5: one dot per band along a moving object's path) is a view mode of the flipbook, not a separate feature. It uses the frames and mover positions the flipbook already loads. Priority P1, built after basic playback works.

(1) **Completeness (D4):** plant synthetic movers in memory in this area's recorded cutouts, run the same pipeline, report the share recovered per S/N and rate bin with intervals. No single "catch rate" number. A **planted test mover** (one fixed mover near the detection limit) is its first, visible step. None of the four changes the "unexplained, not a discovery" wording, and no claim goes beyond the squares tested. (6) **Why, for reviewers:** the SPHEREx catalogue covers known orbits only and leaves unknown-object mining to the community (Lisse, Bauer and Kim 2024). A community researcher will not trust a list of leads without its sensitivity, its false-alarm rate and a sign that a lead is one body; these four supply exactly that (A16.8).

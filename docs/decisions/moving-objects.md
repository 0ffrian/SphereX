# Decisions: Moving objects: Track and Area search

> **Part of:** the decision log ([index](README.md)) · **Holds:** Rainbow Trails, frames for moving objects, the Track tool, Area search and Discovery · **Authority:** highest; an entry here wins over [rendering/](../rendering/README.md) and [architecture/](../architecture/README.md) (see the index for precedence)

## D-28 Rainbow Trails is a flipbook view mode (answers Q-04)

- **Decision:** Rainbow Trails (handover §5: one dot per band along a moving object's path) is a view mode of the flipbook, not a separate feature. It uses the frames and mover positions the flipbook already loads. Priority P1, built after basic playback works.
